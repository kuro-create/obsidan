# 証拠：あなたの証明書の中身から読み取れるポイント

あなたが貼った証明書の抜粋：

コード

```
Issuer: CN = rocky2, C = US, L = Santa Clara
Subject: CN = rocky2, C = US, L = Santa Clara
```

- **Issuer（発行者）＝ Subject（証明対象）** → これは **自己署名証明書の特徴そのもの**
    

さらに：

コード

```
X509v3 Basic Constraints: critical
    CA:TRUE
```

- 自分自身を CA として扱っている → 公的 CA ではないため、ブラウザは絶対に信頼しない
    

そして SAN も：

コード

```
DNS:rocky2, DNS:localhost
```

これはあなたが OpenSSL で作った証明書で、 **CN/SAN は正しく設定されている** → しかし **自己署名である限りブラウザは信頼しない**
