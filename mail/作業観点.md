# 🧩 手順 1：Postfix の main.cf を編集

コード

```
sudo vi /etc/postfix/main.cf
```

以下を追加または修正します。

コード

```
# リレー先（587 番ポート）
relayhost = [dkim-mail.example.com]:587

# SASL 認証を有効化
smtp_sasl_auth_enable = yes
smtp_sasl_password_maps = hash:/etc/postfix/sasl_passwd
smtp_sasl_security_options = noanonymous

# TLS を有効化
smtp_use_tls = yes
smtp_tls_security_level = encrypt
smtp_tls_CAfile = /etc/ssl/certs/ca-certificates.crt
```

### ✔ ポイント

- `relayhost` は **[] で囲む**（DNS MX を引かせないため）
    
- `smtp_tls_security_level = encrypt` により **TLS 必須**
    
- `smtp_sasl_security_options = noanonymous` は必須
# 手順 2：SASL 認証情報を作成

コード

```
sudo vi /etc/postfix/sasl_passwd
```

内容：

コード

```
[dkim-mail.example.com]:587 username:password
```

### ✔ ポイント

- `username` と `password` は **リレー先 Postfix の SASL アカウント**
    
- ドメイン名は relayhost と完全一致させる
    

# 🧩 手順 3：postmap でハッシュ化

コード

```
sudo postmap /etc/postfix/sasl_passwd
```

権限を安全にする：

コード

```
sudo chmod 600 /etc/postfix/sasl_passwd*
```

# 🧩 手順 4：Postfix を再起動

コード

```
sudo systemctl restart postfix
```

# 🧩 手順 5：ログで送信確認

```
sudo tail -f /var/log/mail.log
```

# 🧠（重要）リレー先（DKIM サーバ）側で必要な設定

あなたの DKIM サーバ側では：

### ✔ submission（587）を有効化

`/etc/postfix/master.cf` に以下があること：

コード

```
submission inet n       -       y       -       -       smtpd
  -o smtpd_tls_security_level=encrypt
  -o smtpd_sasl_auth_enable=yes
```

### ✔ SASL 認証を有効化

`/etc/postfix/main.cf`：

コード

```
smtpd_sasl_auth_enable = yes
smtpd_sasl_type = dovecot
smtpd_sasl_path = private/auth
```

（Dovecot SASL を使う場合）

### ✔ WordPress サーバ用の SMTP アカウントを作成

→ これが `username:password` になる
