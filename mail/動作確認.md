# 🟦 Step 1：Postfix の設定構文チェック（最初に必ず）

コード

```
sudo postfix check
```

✔ エラーが出なければ OK ✔ 出た場合は設定ファイルの typo を修正

# 🟦 Step 2：587/TLS でリレー先に接続できるか確認

コード

```
openssl s_client -connect dkim-mail.example.com:587 -starttls smtp
```

成功すると：

- `250 STARTTLS`
    
- 証明書情報
    
- `250 AUTH LOGIN PLAIN`
    

などが表示される。

✔ ここで TLS が確立できれば、ネットワーク・ポートは問題なし。

# 🟦 Step 3：SASL 認証が成功しているかログで確認

Postfix を再起動：

コード

```
sudo systemctl restart postfix
```

ログを監視：

コード

```
sudo tail -f /var/log/mail.log
```

成功例：

コード

```
postfix/smtp[...] Trusted TLS connection established
postfix/smtp[...] 235 2.7.0 Authentication successful
```

失敗例：

コード

```
SASL authentication failed
535 5.7.8 Authentication credentials invalid
```

✔ ここで認証が通れば、587 + SASL の設定は成功。

# 🟦 Step 4：実際にメールを送信して配送ログを確認

テストメール送信：

コード

```
echo "test mail" | mail -s "test" yourname@gmail.com
```

ログを確認：

コード

```
sudo tail -f /var/log/mail.log
```

成功例：

コード

```
postfix/smtp[...] 250 2.0.0 Ok: queued as ...
```

✔ ここで「queued as」が出れば、リレー先に正常に渡っている。

# 🟦 Step 5：Gmail 側で DKIM/SPF/DMARC を確認

Gmail で受信したメールを開き：

**右上の「︙」→「メッセージのソースを表示」**

以下が PASS になっていれば完璧：

コード

```
SPF: PASS
DKIM: PASS
DMARC: PASS
```

特に重要なのは：

コード

```
DKIM: PASS (d=example.com)
```

✔ From ドメインと d= が一致していることを確認 ✔ これで DKIM alignment も PASS

# 🔥 まとめ（孝汰さん向けに最適化）

587 + SASL の動作確認は以下の 5 ステップで確実に行えます：

1. postfix check
    
2. openssl で 587/TLS の疎通確認
    
3. mail.log で SASL 認証成功を確認
    
4. テストメール送信 → ログ確認
    
5. Gmail で DKIM/SPF/DMARC を確認
    

この順番で進めれば、 **どこで問題が起きても即座に切り分け可能**です。
