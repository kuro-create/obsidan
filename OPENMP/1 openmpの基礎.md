# **STEP 1：並列処理の基礎（概念編）**

#openmp

## 🎯 目的

OpenMP を学ぶ前に、**なぜ並列化すると速くなるのか**を理解する。

## 🧠 1-1. 並列処理とは

CPU が複数の仕事を同時に処理すること。

- **直列処理（シングルスレッド）** 1つずつ順番に実行する。
    
- **並列処理（マルチスレッド）** 複数の CPU コアが同時に処理する。
    

## 🧵 1-2. スレッドとは

プログラムの中で「独立して動く小さな実行単位」。

例：

- 料理人が1人 → 直列
    
- 料理人が4人 → 並列
    

## 🔗 1-3. データ依存性

並列化できるかどうかは **ループ内の処理が独立しているか**で決まる。

### 並列化できる例

c

```
a[i] = b[i] + c[i];
```

→ 各 i の計算は独立。

### 並列化できない例

c

```
a[i] = a[i-1] + 1;
```

→ 前の結果に依存している。

## 📐 1-4. Amdahl の法則（並列化の限界）

並列化できない部分があると、性能は頭打ちになる。
